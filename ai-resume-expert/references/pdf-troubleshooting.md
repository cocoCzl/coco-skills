# PDF 按需故障排查

只在实际错误或依赖疑问时读取。先保留已确认 Markdown、可打印 HTML、错误码与渲染尝试记录。

- 缺少本地渲染器、Poppler 或中文字体：按当前系统检查具体缺项，可运行 `resume_skill.py doctor`；不自动安装或上传私人材料。缺少验收能力时明确未验证范围。
- LibreOffice 出现 `Abort trap: 6`（退出码 `134`）：这是渲染失败，不自动认定为沙箱问题。检查渲染日志、配置目录可写性和本地依赖，按可用渲染器降级。
- 仅在实际权限拒绝且已确认当前平台/沙箱约束是原因时，才申请所需的最小权限。macOS 的受限父进程可能导致子进程仍受限；确需沙箱外执行时，范围精确到整个 `resume_skill.py render` 命令，仅放行内部 `soffice` 可能无效。不要关闭整个 Codex 沙箱。
- 不可写输出目录优先换到用户已授权的可写工作区。权限申请被拒绝或渲染仍失败时，交付 Markdown + HTML，并说明 PDF 未生成/未验收。
- PDF 有截断、重叠、缺字、超页或源稿不一致：修正文案/样式后重新渲染并检查，不能以用户签收替代自动校验或 Agent 视觉检查。
