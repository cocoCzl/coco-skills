# 参考资料按需加载索引

需要选资料时查本索引。先理解任务并复用上下文；每进入一个阶段只读该阶段需要的资料，已读内容没有变化不重复读。主入口已给出真实性、授权和最低证据门槛，不用为简单首轮再加载整套规则。

| 阶段/条件 | 何时读取 |
|---|---|
| 理解需求 | 任务清楚时无需加读；岗位不明、交叉或超出范围才读 [`role-routing.md`](role-routing.md) |
| 收集证据 | 实际缺少角色、行动、结果时读 [`interview-and-readiness.md`](interview-and-readiness.md)；需要证据追踪、冲突处理、JD 映射、项目取舍或职业库时读 [`evidence-jd-and-projects.md`](evidence-jd-and-projects.md) |
| 本地代码/文档 | 扫描前读 [`repository-evidence-and-confidentiality.md`](repository-evidence-and-confidentiality.md)，复用已有范围授权 |
| 诊断 | 读 [`resume-diagnosis.md`](resume-diagnosis.md)；岗位专项判断时再选一个岗位策略 |
| 改写/生成 | 开始写正文时读 [`common-resume-rules.md`](common-resume-rules.md) 和一个对应岗位策略；不再预读访谈/证据治理全套 |
| 自审/交付 | 正文形成后读 [`output-and-quality-gates.md`](output-and-quality-gates.md) 的自审与交付部分；只诊断无需加载生成模板 |
| PDF | 用户要求导出且内容已确认时，读 [`pdf-delivery.md`](pdf-delivery.md)；实际失败再读 [`pdf-troubleshooting.md`](pdf-troubleshooting.md) |
| 确定性工具/JSON | 需要结构化证据或简历包时读 [`../schemas/README.md`](../schemas/README.md)，再选择对应 Schema |
