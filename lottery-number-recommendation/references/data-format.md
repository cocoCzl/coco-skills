# 内部标准化历史格式

这是自动官方同步写入本地历史快照时使用的内部 JSON 形态，不是面向用户的导入功能。`sequence` 是从当前已验证历史范围起点开始的连续正整数，用来可靠检查完整性；`issue` 保留官方展示期号。大乐透范围从首期开始；双色球当前从官网可得的 `2013001` 开始。每条记录必须有开奖日期和完整分区号码。

以下仅为字段示意，尖括号内容不是可运行 JSON，也不代表真实开奖；实际值必须来自官方同步记录。

```text
双色球：
{ "game": "ssq", "draws": [{
  "issue": "<官方期号，当前范围从 2013001 开始>",
  "sequence": <当前范围内从 1 开始的连续序号>,
  "draw_date": "<官方开奖日期，YYYY-MM-DD>",
  "red": [<6 个官方红球号码>], "blue": [<1 个官方蓝球号码>]
}] }

大乐透：
{ "game": "dlt", "draws": [{
  "issue": "<官方期号，从首期 07001 开始>",
  "sequence": <从首期开始的连续序号>,
  "draw_date": "<官方开奖日期，YYYY-MM-DD>",
  "front": [<5 个官方前区号码>], "back": [<2 个官方后区号码>]
}] }
```

自动同步会保留官方端点、获取时间、原始分页响应和哈希。合并后 `sequence` 必须从 1 无间断覆盖到当前末期；同步器会自动核验最新期，不接受用户手动标记当前性。
