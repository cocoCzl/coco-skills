# 内部标准化历史格式

这是自动官方同步写入本地历史快照时使用的内部 JSON 形态，不是面向用户的导入功能。`sequence` 是从当前已验证历史范围起点开始的连续正整数，用来可靠检查完整性；`issue` 保留官方展示期号。大乐透范围从首期开始；双色球当前从官网可得的 `2013001` 开始。每条记录必须有开奖日期和完整分区号码。

```json
{
  "game": "ssq",
  "draws": [
    {
      "issue": "2003001",
      "sequence": 1,
      "draw_date": "2003-02-23",
      "red": [1, 2, 3, 4, 5, 6],
      "blue": [7]
    }
  ]
}
```

大乐透使用：

```json
{
  "game": "dlt",
  "draws": [
    {
      "issue": "07001",
      "sequence": 1,
      "draw_date": "2007-05-30",
      "front": [1, 2, 3, 4, 5],
      "back": [6, 7]
    }
  ]
}
```

自动同步会保留官方端点、获取时间、原始分页响应和哈希。合并后 `sequence` 必须从 1 无间断覆盖到当前末期；同步器会自动核验最新期，不接受用户手动标记当前性。
