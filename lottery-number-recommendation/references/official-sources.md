# 官方自动同步来源

本 Skill 只使用官网页面自身公开调用、无需登录或身份凭据的 JSON 接口。该判断依据是公开开奖页面加载时的正常浏览器请求；它不是对网站条款作出的额外法律解释。客户端只发送常规浏览器请求头，不使用 Cookie、验证码令牌、登录自动化或任何访问限制绕过方式。

| 彩票 | 官方站点与接口 | 访问与范围 | 保存方式 |
|---|---|---|---|
| 大乐透 | 中国体彩网 `webapi.sporttery.cn/gateway/lottery/getHistoryPageListV1.qry` | 公开分页查询；已验证从 `07001` 起 | 每次同步保存原始分页响应、哈希、来源 URL 与标准化版本 |
| 双色球 | 中国福彩网 `www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice` | 公开分页查询；当前接口与开奖公告归档均从 `2013001` 起 | 每次同步保存原始分页响应、哈希、来源 URL 与标准化版本 |

## 失败与升级规则

- HTTP 错误、网络错误、格式异常、分页数量不符或访问限制提示都视为同步失败；不尝试重试访问限制或绕过限制。
- 同步失败会保留最后一个历史快照以便审计，但将当前数据状态标为不可用于推荐，直至官方同步成功。
- 双色球当前“未出现”只针对 `2013001` 至最新已开奖期的已校验官网范围。若该官方来源自然提供从 `2003001` 起的连续记录，下一次全量同步会创建新版本并自动升级为全历史范围。
