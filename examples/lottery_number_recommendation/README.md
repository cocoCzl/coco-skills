# 大乐透与双色球号码推荐：使用指南

这个 Skill 不要求你上传、下载或维护开奖数据。第一次使用时，agent 会自动从已验证的官方来源顺序同步可用历史并保存到当前工作目录的 `data/lottery-number-recommendation/`；以后只自动更新新增期次。

## 1. 安装到 Codex

在 `coco-skills` 仓库根目录执行：

```bash
cp -R lottery-number-recommendation ~/.codex/skills/
```

重新开始 Codex 会话后，Skill 会在你明确提到大乐透或双色球并要求选号、推荐、预测、热号、冷号或回测时自动触发。你不需要输入 Skill 名称、运行脚本或传入历史文件。

## 2. 首次使用会发生什么

你可以直接说：

```text
帮我生成一串大乐透。
```

agent 会自动：

1. 创建 `data/lottery-number-recommendation/`；
2. 顺序下载并校验官方开奖历史；
3. 保存原始官方响应、标准化历史、数据版本和同步状态；
4. 大乐透只有从首期连续覆盖至最新已开奖期时才生成号码；双色球只有官网可得的 `2013001` 至最新期连续覆盖时才生成号码，并明确展示这一边界；
5. 返回两位数、分区清晰的结果和数据截止期。

首次初始化比后续请求慢，因为需要下载全部历史。同一天的后续请求只增量更新新开奖期；每天第一次请求会全量复核，发现官方对旧期数据的修正。

## 3. 直接对话示例

### 默认随机未出现组合

```text
帮我生成大乐透和双色球各一串号码。
```

未指定模式时，agent 对每种彩票默认给 1 注随机未出现组合。大乐透以首期至今的完整官方历史校验；双色球以官网当前可得的 `2013001` 至今区间校验。若某种彩票数据未就绪，只返回另一种已就绪彩票，并说明原因。

### 只要大乐透

```text
给我一注大乐透号码预测。
```

只返回大乐透的标准单式：前区 5 个号码、后区 2 个号码。

### 热号

```text
双色球给我 3 注最近 50 期强热号。
```

“热号”“高频号”“常出号码”都会触发热号倾向。结果仍保证完整组合没有在已同步历史中出现，并附上精简的近 50 期出现次数。

### 冷号

```text
给我 2 注大乐透冷号，稍微偏冷。
```

“冷号”“遗漏久”“很久没开”都会触发冷号倾向。默认按最新已开奖期的连续遗漏期数计算；“稍微偏冷”“强烈偏冷”可调节倾向强度。

### 避开此前推荐

```text
再来 5 注双色球热号，避开以前推荐过的组合。
```

同一次请求内完整组合始终不重复。跨请求默认可以重复；只有明确说“避开以前推荐过的组合”时，才排除本地审计记录中的组合。

### 查看数据是否就绪

```text
检查大乐透和双色球的数据状态。
```

agent 会展示每种彩票的首期、最新期、更新时间、完整性和是否可生成号码。

### 两种彩票分别设定参数

```text
双色球给我 3 注最近 50 期强热号，避开以前推荐；大乐透给我 2 注稍微偏冷。
```

agent 会先确定性解析这句话，再按各自参数分别同步和生成；不会把双色球的热号参数误用于大乐透。

### 回测

```text
回测双色球的热号、冷号和随机策略效果。
```

agent 会自动更新数据后，以固定随机种子比较三种策略在历史各期的平均命中数和各奖级命中次数。你也可以说“回测大乐透从第 24001 期到第 25001 期”。回测只说明历史表现，不保证未来结果。

## 4. 数据严格规则

- 大乐透使用中国体彩网公开历史接口，并已验证可回溯到首期 `07001`。
- 双色球使用中国福彩网公开接口和开奖公告归档；两者当前均从 `2013001` 起提供记录。双色球会标明“官网历史 2013001 至最新期”，其中“未出现”仅针对这一已校验区间，不表示覆盖 2003 年首期以来的所有历史。
- 若中国福彩网日后公开 `2003001` 起连续且可验证的记录，下一次全量同步会自动创建新版本，并将双色球校验范围升级为从首期至今。
- 不使用第三方站点、旧缓存或用户上传文件补缺；不绕过 WAF、验证码、登录或其他访问限制。
- 官方同步失败、数据缺期、格式异常或最新期不能确认时，不输出该种彩票号码。
- 官方响应中存在已验证奖池或开奖公告链接时，agent 可以附一行上下文；这些信息不参与选号。

## 5. 输出示例

```text
大乐透｜数据已校验至第 26079 期（2026-07-15）
模式：随机未出现组合｜本注历史未出现
1. 前区 03 11 18 24 35 ｜ 后区 02 09
仅供娱乐与参考，不保证中奖。
```

热号和冷号会多一行极简统计；不会输出“必中”“最大概率”或收益承诺。

## 6. 开发测试数据说明

`tests/fixtures/lottery_number_recommendation/` 中的 JSON 只用于自动化测试，绝不是实际可用的开奖历史。真实运行数据仅保存于工作目录 `data/lottery-number-recommendation/`，不要提交到仓库。
