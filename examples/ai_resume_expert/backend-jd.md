# 虚构 JD：Java 高级后端工程师

> 本 JD 仅用于测试，不对应真实公司。

## 职责

- 负责订单域核心服务设计、开发与稳定性建设。
- 治理高并发场景下的幂等、超时、消息一致性与故障恢复。
- 建设可观测性能力，参与线上问题定位和性能优化。
- 与产品、测试和运维协作完成需求交付。

## 要求

- 5 年以上 Java 服务端经验，熟悉 Spring Boot、关系型数据库与 Redis。
- 有 Kafka 或其他消息中间件的生产实践。
- 能解释数据库索引、事务、幂等与常见分布式系统取舍。
- 有 Kubernetes 生产集群治理经验者优先。
- 有团队管理经验者优先。

JD 覆盖示例应把 Kubernetes 生产治理标为“未证实”，把团队管理标为“未证实或不相关”，不得为了匹配而写入简历。
