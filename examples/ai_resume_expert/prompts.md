# 自然语言请求示例

以下内容都应替换为使用者自己的真实信息与授权范围。

## 直接描述生成

> 我要申请 Java 高级后端工程师，没有具体 JD。请根据 `direct-backend-profile.md` 帮我整理简历。缺信息时一次只问我一个最关键的问题。

## 代码与文档辅助

> 我要申请后端工程师。你可以读取我指定的本地项目目录和 README 做静态分析，但先向我确认材料授权；不要执行代码、测试或容器，也不要读取 Git 历史。请先输出项目事实、扫描覆盖和需要我确认的个人贡献。

## 只诊断原简历

> 我要申请 Java 高级后端工程师。只诊断 `legacy-resume.md`，按致命、重大、一般列出问题和修改方向，不要重写整份简历。

## 优化原简历

> 我要申请 Java 高级后端工程师。先诊断 `legacy-resume.md`，再根据我确认的真实经历给修改对照和独立 Markdown 初稿；保留原文件。

## 混合模式与 JD

> 目标是 Java 高级后端工程师。请合并我的描述、授权项目文档、原简历和 `backend-jd.md`。不同来源冲突时先问我；没有证据的 Kubernetes 与团队管理要求不要写进简历。

## PDF 门槛

> 我确认 `sample-resume.md` 的事实、披露内容和联系方式，可以生成最终 PDF。请本地生成并渲染检查中文字体、页数、截断、链接和黑白可读性。

## 不支持岗位

> 我要申请品牌营销总监，请帮我生成一份投递就绪简历。

Skill 应明确首版没有该职业的专家策略，只能有限整理事实和指出通用问题，不能声称已完成专家优化或投递就绪。
